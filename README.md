# InternWala — Online Courses, Tech Bootcamps & Guaranteed Internships

A high-converting, modern LMS and internship landing page inspired by **Udemy's** design language, crafted with React, TypeScript, and Tailwind CSS.

## 🚀 Key Features

- **Udemy-Style UI & Design System**:
  - **Top Promotional Flash Sale Banner** with live real-time countdown timer.
  - **Signature Header**: Brand logo, hoverable Categories mega-menu, global search bar with instant course filtering, Wishlist & Cart counters with animations, and Auth buttons.
  - **Sub-Navigation Category Bar**: Fast access to Development, AI, Cloud, UI/UX, Mobile, and Internship tracks.
  - **Udemy Hero Billboard**: Floating white card with value proposition and verified placement badges.
  - **Trusted Hiring Partners**: Logos of Google, Microsoft, Amazon, Razorpay, Swiggy, Zomato, Flipkart, and Infosys.
  - **"A broad selection of courses & internships"**: Interactive tabbed category browser featuring Udemy course cards with star ratings, bestseller badges, discounts, and quick-action buttons.
  - **Course Detail Preview Modal**: Rich modal showing syllabus, hours, lectures, and enrollment.
  - **Interactive Lesson Player**: Video preview player with seekbar, play/pause, 1x-2x playback speeds, captions, and mute toggle.
  - **Slide-Over Shopping Cart Drawer**: Dynamic cart management with subtotal and checkout.
  - **Wishlist & Toast Notifications**: Instant visual feedback for user interactions.
  - **Learner Success Stories & Social Proof**: Testimonials with verifiable outcomes.
  - **Dual Action Banners**: "Teach on InternWala" and "InternWala Business".
  - **Interactive FAQ Accordion**: Common questions about certificates and internships.
  - **Multi-Column Dark Footer**: Complete Udemy-style footer with language switcher and copyright.
  - **Dark Mode Support**: Seamless toggle between clean light mode and slate dark mode.

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Vite 6**
- **Tailwind CSS 3** with custom Udemy color palette (`#a435f0`, `#2d2f31`, `#f7f9fa`)
- **Lucide React** icons
- **AOS** scroll animations

## 💻 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Build for production
```bash
npm run build
```
