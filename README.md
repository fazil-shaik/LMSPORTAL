# LMS Portal — Landing Page

A pixel-perfect, interactive landing page implementation matching the Figma design:
`https://www.figma.com/design/aOwyFYaSOOqt08aMBchGER/lmsPortal`

## Tech Stack
- **React 18** + **TypeScript**
- **Vite 6**
- **Tailwind CSS 3**
- **Plus Jakarta Sans** typography
- **Original Figma Vector Assets & Icons** (`public/assets/`)

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Build for production
```bash
npm run build
```
Preview the production build:
```bash
npm run preview
```

## Features Implemented
- **Header & Navigation**: Sticky navbar with brand mark, active navigation links, sign in, get started CTA, and mobile hamburger drawer.
- **Hero Section**: Soft mesh gradient background with ambient glow SVG, intention badge, headline typography, CTA button, and social proof.
- **Interactive Player Preview**: Video lesson player with play/pause state, scrubbable seek bar, time counter, interactive 3-step framework (Observation, Human Need, Opportunity), speed toggling, captions, and course metadata.
- **Benefits Row**: 3 key value propositions with icons.
- **Trusted By Section**: Wordmarks for Notion, Stripe, Linear, Webflow, and Figma.
- **Curated Courses**: 3 course cards with custom gradients, ambient glows, series badges, ratings, locked indicators, and enrollment dialog.
- **How It Works**: 4-step progressive learning process.
- **Learner Testimonials**: Webflow, Linear, and Fieldwork student reviews.
- **Interactive FAQ Accordion**: Expandable/collapsible FAQ items with direct email support link.
- **Call-to-Action Banner**: Dark navy banner with next steps CTA.
- **Footer**: Brand mark, multi-column navigation, and legal notice.
